## 🎯 Sobre o projeto

Site pessoal com portfólio de projetos, tecnologias e criações — construído pra reunir num
único lugar o vídeo, o portfólio de projetos e a coleção de criações pedidos na inscrição da
Apple Developer Academy PUCPR.

- **Início** — apresentação e status estilo HUD
- **Projetos** — puxados direto do meu [GitHub](https://github.com/EduardoLopessz)
- **Skills** — tecnologias que domino e as que estou treinando
- **Criações** — Twitch, canal de música e edições no TikTok
- **Sobre** — minha história, com foto e contato

## 📂 Estrutura

```
portfolio-eduardo/
├── index.html        # estrutura e conteúdo
├── styles.css         # estilos e responsividade
├── script.js          # interações (menu, HUD, animações)
└── foto-eduardo.jpg   # foto usada na seção Sobre
```

## 🚀 Rodando localmente

Não precisa de instalação nem servidor: é só abrir o `index.html` no navegador, ou usar uma
extensão tipo Live Server. O deploy é feito via **GitHub Pages** direto da branch `main`.
